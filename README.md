## 🚀 نصب و راه‌اندازی

### پیش‌نیازها

* Python 3.10 یا بالاتر
* BotFather توکن ربات تلگرام از 
* کانال یا گروه (در صورت استفاده از عضویت اجباری)

---

### 1. دریافت پروژه

```bash
git clone https://github.com/Mr-shiravani/Iran-vs.-Turan-game.git
cd Iran-vs.-Turan-game
```

### 2. ساخت محیط مجازی

```bash
python -m venv venv
```

ویندوز:

```bash
venv\Scripts\activate
```

لینوکس / مک:

```bash
source venv/bin/activate
```

### 3. نصب وابستگی‌ها

```bash
pip install -r requirements.txt
```

### 4. تنظیم فایل محیطی

```bash
copy .env.example .env
```

سپس مقادیر موردنیاز را وارد کنید.

| متغیر                | توضیح                |
| -------------------- | -------------------- |
| BOT_TOKEN            | توکن ربات            |
| REQUIRED_CHAT        | کانال یا گروه اجباری |
| DB_PATH              | مسیر پایگاه داده     |
| ADMIN_ID             | شناسه عددی ادمین     |
| ADMIN_PANEL_PASSWORD | رمز پنل مدیریت       |
| ADMIN_PASSWORD       | رمز ورود ادمین       |
| GODMODE_CODE         | کد حالت توسعه        |


### 5. اجرای ربات

```bash
python main.py
```

در صورت اجرای صحیح، پیام زیر در لاگ نمایش داده می‌شود:

```text
جنگ پهلوانان bot is running...
```

### نبرد در گروه

برای مبارزه در گروه، ربات را به گروه اضافه کرده و از دستورات زیر استفاده کنید:

```text
حمله
/attack رستم
/fight @user
سلامت
```

> برخی دستورات نیازمند ریپلای روی پیام بازیکن هدف هستند.

## 📜 دستورات

| دستور           | توضیح                 |
| --------------- | --------------------- |
| /start          | شروع یا بازگشت به منو |
| /cancel         | لغو عملیات فعلی       |
| /ping           | بررسی وضعیت ربات      |
| /chatid         | نمایش شناسه چت        |
| /admin          | پنل مدیریت            |
| /admin_login    | ورود ادمین            |

## 🔒 امنیت

* اطلاعات حساس را فقط در فایل `.env` نگهداری کنید.
* شناسه ادمین را تنها برای حساب اصلی خود تنظیم نمایید.
* از انتشار رمزها و توکن‌ها در مخزن جلوگیری کنید.
* پیش از هر انتشار، پروژه را از نظر اطلاعات حساس بررسی نمایید.
